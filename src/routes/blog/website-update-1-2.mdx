I'm excited to share some recent updates and improvements to the website. Let's go through what's new in this version.

## 🎉 New Features

### Table of Contents Support
A navigation panel is now available on blog posts, privacy policy, and documentation pages, making it easier to navigate through longer content and quickly jump between sections.
![Table of contents](blog-resources/website-update-1-2/tableOfContents.png)

### Documentation Framework
We've laid the groundwork for comprehensive documentation. While still in early stages, the infrastructure is ready and we welcome community contributions to help expand our documentation coverage. If you're interested in contributing, feel free to reach @Burak or @Tiktack in a discord channel.

### New InfoBar Component
Introducing a versatile component for highlighting important information in MDX content:

<InfoBar severity="information" closable>
  This is an example of the new InfoBar component showing an informational message.
</InfoBar>

<InfoBar title='Caution message' severity="caution" closable>
  You can also use it to display warning messages that need attention with title.
</InfoBar>

## 🔧 Enhancements

### Home Page Improvements
- Updated visual design
- Added theme preview showcasing both light and dark modes

### Performance Optimizations
- Style refinements and fixes
- Implemented WebP image format for faster loading times
